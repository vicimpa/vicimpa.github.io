Pixprite.

Редактор, который вырос из игрового рига

Я хотел делать персонажей с игровым ригом и передавать их в движок в своём формате. Из этой задачи вырос Pixprite — редактор пиксель-арта и анимации для браузера и десктопа. Game rig уже работает. Дальше хочу добавить нодовый редактор для процедурных спрайтов.

Что внутри

Изначальная задача редактора — создавать персонажей с игровым ригом и передавать их в собственный движок.

Десктопная версия на Tauri работает на macOS, Windows и Linux. Локальный MCP-сервер позволяет совместимым инструментам читать и редактировать документы.
