О проекте / vicimpa-library

vicimpa-library.

Библиотеки, которые забираю из проекта в проект

В одном репозитории собираю самостоятельные TypeScript-пакеты. В glm лежит математика для графики, rsp связывает React-компоненты с сигналами, а keyboard читает кнопки и оси ввода для игрового цикла.
