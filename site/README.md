# Portfolio sources

Edit project descriptions in `projects.json` and the home-page copy in `home.ru.html` or `home.en.html`. Shared styles and interactions live at the repository root in `style.css` and `workshop.js`.

Run `python3 site/build.py` from the repository root to regenerate the Russian and English pages, sitemap and robots.txt. Python's standard library is sufficient. Commit both the sources and generated pages. GitHub Pages publishes from the root of `master`.
