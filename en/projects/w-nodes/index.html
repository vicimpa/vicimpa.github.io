Project notes / WebAudio Nodes

WebAudio Nodes.

A modular synthesizer made of nodes and cables

WebAudio Nodes connects oscillators, filters, sequencers and samplers into a browser instrument. Control signals run at audio sample rate. Groups become reusable blocks with their own ports.

Inside the project

Expression uses a custom parser to compile formulas into an AudioWorklet, with inputs, math functions and the previous output sample.

MIDI input, sampling, recording, a media library, autosave and .wnodes files support longer sessions. Blocks can contain other blocks.

Built with React, TypeScript and signals. The node design is based on a layout by CUSTOMITY.
