OpenBomber.

Multiplayer Bomberman in the browser

OpenBomber brings bombs, destructible walls and power-ups to a shared browser arena. Players can join public games or create rooms for friends.

MultiplayerDiscord Activities

Inside the project

The current project supports arenas for up to 32 players, bots and Discord Activities.

Keyboard, gamepad and touch controls make the same game playable on different devices.
