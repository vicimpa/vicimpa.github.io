Project notes / YummyWatch

YummyWatch.

Anime, close at hand

An anime player for macOS, Windows and Linux with the YummyAnime catalog, voice and quality selection, a personal collection and saved playback progress. Discord shows the title, episode and viewing progress.

Inside the project

Browse the catalog, search, check the schedule and manage a collection in one app. Choose a source, voice track and quality, adjust playback speed and resume where you left off.

Discord Rich Presence includes artwork, episode details and a native progress bar. Outside playback, it shows the current section and search query. Activity sharing can be turned off in settings.

Built with Preact and TypeScript, with Tauri and Rust on desktop. Installers for macOS, Windows, Linux and Arch Linux are available in GitHub releases.
